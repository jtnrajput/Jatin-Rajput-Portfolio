# Jatin Rajput — Portfolio starter

A responsive, editorial-style marketing portfolio built with Next.js and CSS. Designed as a starting point for deployment to Vercel.

## Before publishing

1. Replace the placeholder email `hello@jatinrajput.com` with the email you want clients/recruiters to use.
2. Verify your LinkedIn and Instagram URLs.
3. Replace the concept project covers with real, permission-cleared screenshots, creatives, website captures and campaign assets.
4. Add verified outcomes only. Do not publish invented reach, leads, revenue, ROAS or conversion figures.
5. Update experience dates, employer names and exact responsibilities after reviewing your CV.
6. Consider adding a downloadable PDF resume and a dedicated case-study page for your strongest 2–3 projects.

## Run locally

Install Node.js (LTS), then from this folder run:

```bash
npm install
npm run dev
```

Open http://localhost:3000

To test a production build:

```bash
npm run build
```

## Deploy to Vercel

1. Create a GitHub repository and upload the contents of this folder.
2. Sign in to Vercel and choose **Add New → Project**.
3. Import the GitHub repository.
4. Keep the detected framework as Next.js and click **Deploy**.
5. Vercel will provide a free `*.vercel.app` URL.

## Current project cards

The cover graphics are CSS-generated visual placeholders to establish the layout. They are not original client assets and should not be presented as actual client campaign work. The page explicitly labels them as concept covers while the real case studies are being assembled.
